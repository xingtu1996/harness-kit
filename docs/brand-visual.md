# XingTu Design · 行途品牌视觉规范

> Build in public：这里是「行途」自媒体品牌的所有视觉设计标准。
> 如果你看到了这里，说明你在意视觉细节——欢迎提意见，我们持续迭代。

---

## 三原色体系

| 色 | 值 | 用途 |
|---|---|---|
| 行途橙红 | `#F2644F` | 强调色：节标题字+下划线、封面强调词、信息图标注 |
| 纯黑 | `#1a1a1a` | 正文主字、纯黑封面底、信息图黑条 |
| 纯白 | `#FFFFFF` | 纯白封面底、信息图底、阅读页底 |
| 灰阶 | `#7A8087` / `#A8ADB3` | 副标、图注、版权行 |

**禁用**：纸白 `#F7F5F2`（偏灰）；大红 `#d71a1b`（旧主色，太艳）；蓝/荧光绿等其他主色。

> 为什么选橙红？橙红暖、不刺眼，在纯白底上有足够对比但不攻击性——适合「工程实践者」的克制感。大红太像促销，蓝色烂大街，荧光绿太潮。

## 封面设计规范

### 律动：黑白交替
- 一篇黑底、一篇白底交替——不是审美随机，是让读者在信息流里「隔一篇换个节奏」，避免视觉疲劳
- 白底 = 纯白 `#FFFFFF`；黑底 = 纯黑 `#1a1a1a`（不用深灰）
- 头条尺寸：900×383（2.35:1）

### 排版规则
- 黑底封面：白字主标 + 橙红强调词
- 白底封面：黑字主标 + 橙红强调词
- 主标字数×字号 < 470px 防孤字换行（12 字用 ≤38px）
- 左上合集名橙红字标签 + 主标 + 副标

> 2026-09-21 起：封面左下角不再放「行路小人」品牌符号（美感不佳，已移除）。

## 正文排版主题

### Review 评测风（橙红系）

这是默认正文主题——**方法论/技术/数据/认知干货文**统一使用：

- h2 节标题：橙红字 + 橙红下划线（inline-block 通栏）
- 加粗：全篇 ≤3 处，加粗字色用纯黑（不用橙红/红色）
- 强调色：统一 `#F2644F`，不出现两个红打架
- 对齐方式：正文 left（不 justify，防短行字间距拉宽）

### Pure 零色块（仅纯情绪/回忆类随笔）
- 无强调色、无色块、无下划线——纯文字本身说话

> 为什么分文体？干货文需要视觉骨架帮读者扫读；情绪文不需要装饰，装饰反而稀释情绪。

## 信息图 / 引子图

- 底 = 纯白 `#FFFFFF`
- 体系 = 黑橙红灰三原色
- 密度：≥1 图/千字，A 档 8-12 张，每大节 ≥1 张
- 素材只取正文原文，不编造；外部数据图标来源；自制图标「行途 · 合集名」

四类模板：三栏对比 / 数字卡 / 卡片矩阵 / 概念示意。

---

## 首屏公式

```
标题 → 一句话摘要（≤60字：翻了谁+跑了什么+判断）
     → 引子图（论点图非装饰）
     → 先说结论
     → 我是谁一句
```

- 摘要在引子图**前**——信源透明是信任资产
- 不放目录列表——首屏第一屏就是内容本身，不拿目录占空间
- 不放自我反思开头——第一句就是钩子

---

## 文末律动

- 节间**无**分割线（h2 橙红下划线承担分隔）
- 文末块间**有**分割线
- 求赞：一句，不排比不四连
- 延伸阅读：可点链接 + 灰副注
- 版权行：左对齐
