# coding-gate —— 开发交付门禁（resident）

> 本规则由 harness-kit `code-delivery` preset 生成。用途：AI 在写代码前/后的硬性自检（A9 立品实证件）。

## 改动前（Gate 1）
- [ ] 一句话：改什么 / 为什么 / 影响面（波及哪些文件/调用方）
- [ ] 涉及数据/外部系统：退出、幂等、回滚三条件已明确
- [ ] 库里有同款实现？先搜再用（复用优先于重造）

## 改动后（Gate 2）
- [ ] 有验证（单测/接口/最小脚本证明新行为），且跑了绿
- [ ] 未破坏既有：相关测试/冒烟通过
- [ ] 提交小步、意图单一

## 禁止（Rules 是愿望、Hook 是墙的例外处——确定性禁止用脚本/hook 拦，此表为兜底）
- 未说明就改共享/公共路径
- 把调试日志、密钥、临时文件带进提交
- "看着对"就交付（无任何验证）

## 体积
- CLAUDE.md <300 行、本规则 <100 行；超标先删后增
- 跑 `harness-kit size --json` 看产物预算通过性
